# Omnichannel Batch Renderer 📱

E-commerce requires true omnichannel presence. This After Effects automation tool takes a master 16:9 or 1:1 composition and automatically builds platform-specific aspect ratios while respecting UI safe zones.

## Supported Output Formats
*   **TikTok / Reels / Shorts:** 9:16 (1080x1920) with automated UI safe-zone overlays.
*   **Meta Feed:** 4:5 (1080x1350) 
*   **YouTube In-Stream:** 16:9 (1920x1080)

## How it Works
Select your master comp, run `Luan_BatchResize.jsx`, and the script will generate nested comps for each aspect ratio, applying auto-scale expressions to background elements while keeping text layers bound to title-safe margins.
